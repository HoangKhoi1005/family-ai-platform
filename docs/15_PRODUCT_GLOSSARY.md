# Thuật ngữ

| Code / domain    | UI tiếng Việt             | Nghĩa                                               |
| ---------------- | ------------------------- | --------------------------------------------------- |
| FamilySpace      | Nhà mình / Gia đình       | Không gian dữ liệu của một nhà                      |
| Home             | Nhà mình                  | Màn hình tổng quan; không phải thực thể FamilySpace |
| User             | Tài khoản                 | Danh tính đăng nhập                                 |
| FamilyMembership | Quyền tham gia            | Tư cách trong một nhà                               |
| Member           | Người thân                | Hồ sơ người trong gia phả                           |
| FamilyTree       | Gia phả                   | Sơ đồ quan hệ                                       |
| Relationship     | Quan hệ                   | Cạnh có kiểu đã ghi nhận                            |
| Household        | Hộ gia đình               | Nhóm sinh hoạt, chưa có module MVP                  |
| Branch           | Nhánh gia đình            | Nhánh do gia đình xác định                          |
| Event            | Ngày quan trọng / Sự kiện | Định nghĩa lịch                                     |
| EventOccurrence  | Lần diễn ra               | Một lần cụ thể của sự kiện                          |
| Calendar         | Lịch nhà                  | Màn hình ngày và sự kiện                            |
| Moment           | Khoảnh khắc               | Ảnh chia sẻ thân mật                                |
| Memory           | Kỷ niệm                   | Tư liệu lưu giữ có chủ ý, giai đoạn sau             |
| Album            | Bộ ảnh                    | Nhóm ảnh, không đồng nghĩa Memory                   |
| ChatThread       | Cuộc trò chuyện           | Phòng chat; tab là Trò chuyện                       |
| Message          | Tin nhắn                  | Đơn vị nội dung chat                                |
| Document         | Tài liệu                  | Tư liệu có nguồn và quyền                           |
| Notification     | Thông báo                 | Thông tin gửi tới người nhận                        |
| Reminder         | Lời nhắc                  | Thông báo theo lịch                                 |
| ChangeRequest    | Đề xuất thay đổi          | Chờ duyệt trước khi áp dụng                         |
| Admin            | Quản trị viên             | Vai trò quản lý nhà                                 |
| AI query         | Hỏi chuyện nhà            | Hỏi đáp theo dữ liệu được phép                      |

Tên hiển thị theo cấu hình: “Bác Hai”, “Cô Ba”, “Dì Năm”. Không dùng số thứ tự trong tên gọi để suy ra thứ tự sinh chính thức. “Nội/ngoại” có thể là quan hệ tương đối với người xem, không phải nhãn global đủ để suy luận mọi vai vế.
